# 📊 Sales Analytics Dashboard

## 📌 Overview

The **Sales Analytics Dashboard** is an interactive Microsoft Excel dashboard created to analyze sales performance across products, regions, dates, and salesmen.

The dashboard uses Pivot Tables, Pivot Charts, Slicers, and Timeline filters to transform raw sales data into meaningful business insights.

---

## 🎯 Objectives

- Monitor overall sales performance
- Analyze sales by product
- Compare sales across regions
- Identify top-selling products
- Identify low-selling products
- Analyze salesman performance
- Identify top-performing salesmen
- Identify poor-performing salesmen
- Track sales trends over time
- Analyze product quantity sold

---

## 📑 Dashboard Pages

### 🏠 1. Dashboard

The main dashboard provides an overview of sales performance.

**KPIs:**
- Total Amount
- Total Sales

**Charts:**
- Sales by Amount
- Sales of Product
- Sales by Region

---

### 📦 2. Products Analysis

The Products page focuses on product-level performance.

**Analysis includes:**
- Sales of Product by Quantity
- Top 3 Selling Products
- Top 3 Less Selling Products

**Products analyzed:**
- Keyboard
- Monitor
- Mouse
- Printer
- Scanner
- Speaker

---

### 👤 3. Salesman Analysis

The Salesman page analyzes individual salesman performance.

**Analysis includes:**
- Salesman Performance
- Top 3 Performing Salesmen
- Top 3 Poor Performing Salesmen

This helps identify high-performing and low-performing sales representatives.

---

## 🎛️ Interactive Filters

The dashboard includes interactive filters for:

### 📅 Date
Users can select specific months or periods using the timeline.

### 🌎 Region
- East
- North
- South
- West

### 📦 Item
- Keyboard
- Monitor
- Mouse
- Printer
- Scanner
- Speaker

The charts and KPIs update based on the selected filters.

## 🚀 How to Use

1. Open the Excel dashboard.
2. Go to the **Dashboard** page.
3. Use the **Date**, **Region**, and **Item** filters.
4. Review the KPI values.
5. Analyze the charts.
6. Go to **Products** for product-level analysis.
7. Go to **Salesman** for salesman performance analysis.
